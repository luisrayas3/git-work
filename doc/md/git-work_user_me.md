## git-work user me

Display the identity you write as

### Synopsis

Print the identity this repository writes as, the one the first mutating
command settled from git's user.name and user.email.

This is the document work.user.me() returns; --format text prints the line
the bare `git work user` prints for it.

```
git-work user me [flags]
```

### Options

```
  -f, --format string   Select the output formatting style. Valid values are [json,text] (default "json")
  -h, --help            help for me
```
