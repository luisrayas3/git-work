## git-work bridge pull

Pull updates from a remote bug tracker

```
git-work bridge pull [NAME] [flags]
```

### Options

```
  -n, --no-resume      force importing all issues
  -s, --since string   import only issues updated after the given date (ex: "200h" or "june 2 2019")
  -h, --help           help for pull
```
