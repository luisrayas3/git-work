## git-work flow rm

Remove a flow from the local repository

### Synopsis

Remove a flow's local ref. This is local: the flow comes back on the next
pull. The replicated removal is archive.

```
git-work flow rm NAME [flags]
```

### Options

```
  -h, --help   help for rm
```
