## git-work issue log

Print an issue's history

### Synopsis

Print the issue's history: every operation, oldest first, in the shape the
store holds it. This is what a status report is generated from.
ID is an id prefix or an alias.

```
git-work issue log ID [flags]
```

### Options

```
  -f, --format string   Select the output formatting style. Valid values are [json,text] (default "json")
  -h, --help            help for log
```
