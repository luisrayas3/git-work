## git-work bug deselect

Clear the implicitly selected issue

```
git-work bug deselect [flags]
```

### Examples

```
git work issue select 2f15
git work issue comment
git work issue status
git work issue deselect

```

### Options

```
  -h, --help   help for deselect
```
